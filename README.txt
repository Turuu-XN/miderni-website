MIDErNI WEBSITE STARTER
=======================

Files
- index.html: page structure and content
- style.css: responsive futuristic visual design
- script.js: language switching, mobile menu, active navigation

Preview
1. Unzip this folder.
2. Open index.html in a browser.
3. For a local development server, open a terminal in this folder and run:
   python3 -m http.server 8000
   Then visit http://localhost:8000

Before publishing
- Change hello@miderni.com in index.html to your real email address.
- Confirm the Miderni brand name, domain and trademark availability.
- Portfolio cards are clearly marked as concept projects, not client work.
- Update service descriptions and add real project screenshots as you complete work.
- This is a static front-end site. The contact link opens the visitor's email app; it does not submit to a database.

Suggested free deployment
- GitHub Pages or Cloudflare Pages.
- Connect your own domain after checking availability.
